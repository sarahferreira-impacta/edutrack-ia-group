## Tecnologias Utilizadas
* **VS Code** — Ambiente de desenvolvimento
* **Git & GitHub** — Controle de versão e hospedagem de código
* **Node.js** — Ambiente de execução JavaScript
* **OpenSpec** — Especificação e documentação
* **Xano** — Backend No-Code/Low-Code

## Sobre o Projeto
> *O EduTrack AI é um sistema inteligente focado em acompanhar, analisar e otimizar o engajamento e a jornada de aprendizado dos alunos. Unindo recursos de IA e backend em nuvem, a plataforma transforma dados educacionais em insights práticos para apoiar tanto estudantes quanto educadores.*
